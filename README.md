# Shellfri

A minimal Android launcher designed to simplify your home screen and help you stay focused.

## Features

- Clean and minimal interface
- Normal Mode and Focus Mode
- Customizable home screen
- App drawer and folders
- App shuffling to break repetitive app-opening habits

## Tech Stack

- Kotlin
- Jetpack Compose
- Room Database
- DataStore
- WorkManager

## Development

Shellfri is currently under active development. New features and improvements are being added regularly.
